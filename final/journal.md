## Features

### Canvas level
The following actions can be done at the level of the entire canvas:

- The user can export the result as an image.
- The user can specify the resolution of the image.
- The user can select a pre-specified color palette
- The user can determine the order of certain operations to adjust some visual effects. For example, the user could change the font size, then apply blur.

### Typography level 

The following transformations will be able to be applied at the level of the entire typographic element. The entire text will be transformed in a single function:

- Apply some noisiness / disturbance
- Shear the text
- Scale X, Y
- Select the font family
- Apply a grid layout or a line layout
- Interrupt the text via an item the background color (eg. applying an array of horizontal lines)
- Adjust the outline   

### Per-letter

The following transformations can apply per letter and are moderated by the user via a factor that scales the transformation.  The function applies to each element separately rather than applying to the whole text.

- letter scale on x, y axis
- letter rotation
- letter position (eg. on a curve)
- blur (eg. letters will be drawn at different blurring level)

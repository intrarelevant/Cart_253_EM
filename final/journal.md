## Features

### Canvas level
The following actions can be done at the level of the entire canvas:

- The user can export the result as an image.
- The user can specify the resolution of the image.
- Select a color palette
- The user can determine the order of certain operations to adjust the visual effect. For example, the user could change the font size, then apply blur.

### Typography level 

The following transformations will be able to be applied at the level of the entire typographic element. The entire text will be transformed in a single function:

- Apply some noisiness / disturbance
- Shear the text
- Select the font family
- Apply a grid layout or a line layout


### Per-letter

The following transformations can apply per letter and are moderated by the user via a factor. The function applies to each element separately

- letter scale on x, y axis
- letter rotation
- letter position (eg. on a curve)
- blur (eg. letters will be drawn at different blurring level)
